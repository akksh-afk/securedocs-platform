# Public benchmark sources for robust testing

The project does not bundle real personal identity records or live CCTNS data.
Use these public research datasets for authorized benchmarking:

- MIDV-2020 — identity-document analysis benchmark with scans, photos and video frames, artificial faces and rich annotations: https://arxiv.org/abs/2107.00396
- ICDAR SmartDoc 2015 Challenge 1 — smartphone document capture with realistic perspective, blur, illumination and partial occlusion: https://zenodo.org/records/1230218
- ICDAR SmartDoc 2015 Challenge 2 — mobile OCR under varying capture conditions: https://zenodo.org/records/2572929
- SmartDoc 2017 reconstruction test data — hand-held mobile video with blur, highlights, occlusions and fragments: https://github.com/smartdoc2017-competition/test_dataset

CCTNS itself is a government law-enforcement system. This repository intentionally uses clearly marked synthetic CCTNS-style records rather than real CCTNS case/identity data.
